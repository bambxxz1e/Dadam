Sweet Nightmare
프로젝트 소개

Sweet Nightmare는 Python의 Pygame 라이브러리를 활용하여 제작한 2D 보스전 중심 액션 게임입니다.
플레이어는 이동, 점프, 공격을 활용하여 보스를 상대하며 보스는 체력 기반 페이즈 시스템과 투사체 공격 패턴을 사용합니다.

또한 게임의 몰입도를 높이기 위해 슬로우 모션, 카메라 흔들림, 페이드 연출, 체력바 애니메이션 등의 연출 요소를 구현했습니다.

개발 목적
상태(State) 기반 게임 흐름 관리
플랫폼 충돌 처리 및 물리 시스템
보스 AI 및 페이즈 시스템
게임 연출 효과 구현

기술 스택
Python
Pygame

주요 기능
1. State 기반 게임 구조
TITLE → FADE_TO_READY → READY → PLAYING → GAME_OVER
각 상태에서 입력 처리, 업데이트, 렌더링을 분리하여 게임 흐름을 명확하게 관리할 수 있도록 설계했습니다.

2. 객체지향 기반 게임 구조
게임 객체는 공통 부모 클래스인 Entity를 기반으로 설계했습니다.
Entity
 ├ Player
 ├ Boss
 └ Fairy
공통 기능(체력, 사망 처리, 위치 관리)을 상위 클래스에서 관리하여 코드 재사용성과 확장성을 높였습니다.

3. 플랫폼 충돌 및 이동 시스템
플레이어 이동은 X축과 Y축을 분리한 충돌 처리 방식을 사용했습니다.
1. X축 이동
2. X축 충돌 처리
3. Y축 이동
4. 착지 판정
이를 통해 플랫폼 위에서 자연스럽게 이동하고 착지하는 구조를 구현했습니다.

4. 보스 페이즈 시스템
보스는 체력에 따라 3단계 페이즈로 변화합니다.
Phase	체력 기준	특징
Phase 1	70% 이상	기본 이동 및 공격
Phase 2	70% 이하	이동 속도 증가
Phase 3	40% 이하	공격 강화
페이즈가 변경될 때 카메라 흔들림과 색상 변화 연출을 추가하여 전투의 긴장감을 높였습니다.

5. 투사체 공격 시스템
보스는 무작위 방향으로 투사체를 발사합니다.
vel_x = speed * random.uniform(-1.5, 1.5)
vel_y = speed * random.uniform(-1.5, 1.5)
페이즈가 높아질수록 투사체 개수가 증가하도록 설계했습니다.

6. 전투 연출 시스템
전투의 몰입도를 높이기 위해 다음 연출을 구현했습니다.
슬로우 모션 : 공격 및 피격 순간 시간 지연
카메라 흔들림 : 타격감 강화
페이드 인/아웃 : 장면 전환 연출
보스 폭발 파티클 : 보스 사망 연출

프로젝트를 통해 배운 점
게임 루프 구조 설계
상태 기반 시스템 설계
플랫폼 충돌 처리 구현
보스 AI 패턴 구현
게임 연출 요소 설계

특히 단순한 기능 구현보다 연출 요소가 게임 몰입도에 큰 영향을 준다는 점을 경험할 수 있었습니다.
